PASO 1: Abrir el link en tu navegador
────────────────────────────────────
Copia y pega el link correspondiente en tu navegador.
GitHub te llevará a la página de creación de PR.

PASO 2: Verificar el branch
────────────────────────────
Asegúrate que:
- Base: main
- Compare: feature/nombre-del-branch

PASO 3: Agregar título
───────────────────────
Copia el título sugerido de arriba.

PASO 4: Agregar descripción
────────────────────────────
Para Mejora #1 y #2:
1. Abre el archivo PR_MEJORA_X.md
2. Copia TODO el contenido
3. Pégalo en la descripción del PR

Para Documentación:
Usa la descripción corta de arriba.

PASO 5: Agregar labels
───────────────────────
En el panel derecho, agrega los labels sugeridos.

PASO 6: Crear el PR
────────────────────
Click en "Create pull request"

PASO 7: Solicitar review (opcional)
────────────────────────────────────
Si trabajas en equipo, solicita review.
Si trabajas solo, puedes aprobar directamente.
