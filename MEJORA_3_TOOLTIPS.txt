═══════════════════════════════════════════════════════════════════════════════
  📋 DESCRIPCIÓN
═══════════════════════════════════════════════════════════════════════════════

Tooltips nativos con CSS puro que aparecen al hacer hover sobre botones de
acción, proporcionando contexto adicional sin saturar la interfaz.

═══════════════════════════════════════════════════════════════════════════════
  ⏮️ BEFORE (ANTES)
═══════════════════════════════════════════════════════════════════════════════

❌ Tooltip nativo del navegador (inconsistente)
❌ Sin estilo personalizado
❌ Aparece con delay largo
❌ No sigue diseño de la app
❌ Texto genérico del atributo "title"

CÓDIGO BEFORE:
--------------
<button className="icon-btn edit" title="Editar">
  ✏️
</button>

APARIENCIA BEFORE:
------------------
┌──────────┐
│    ✏️    │  ← Botón
└──────────┘
     ↓
  [Editar]  ← Tooltip nativo (feo, inconsistente)

═══════════════════════════════════════════════════════════════════════════════
  ⏭️ AFTER (DESPUÉS)
═══════════════════════════════════════════════════════════════════════════════

✅ Diseño consistente con la app
✅ Animación suave de aparición
✅ Posicionamiento preciso
✅ Tipografía legible
✅ Fondo semi-transparente oscuro
✅ Implementación ligera (CSS puro, sin JS)

CÓDIGO AFTER:
-------------
<button 
  className="icon-btn edit" 
  data-tooltip="Editar actividad"
>
  ✏️
</button>

CSS:
.icon-btn::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 8px);
  background: rgba(0, 0, 0, 0.85);
  color: white;
  padding: 6px 10px;
  border-radius: 6px;
  opacity: 0;
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
}

.icon-btn:hover::after {
  opacity: 1;
  transform: translateY(0);
}

APARIENCIA AFTER:
-----------------
  ┌─────────────────────┐
  │ Editar actividad    │  ← Tooltip estilizado
  └──────────┬──────────┘
             │
       ┌────┴────┐
       │    ✏️   │  ← Botón
       └─────────┘

   Ubicación: Lado derecho de cada tarjeta
   Tooltip: "Editar actividad"
   Qué hacer: Pasa el mouse sobre el botón ✏️
   
3. BOTÓN ELIMINAR (🗑️)
   Ubicación: Lado derecho de cada tarjeta
   Tooltip: "Eliminar actividad"
   Qué hacer: Pasa el mouse sobre el botón 🗑️
